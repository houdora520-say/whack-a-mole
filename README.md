# 🔨 可愛打地鼠遊戲 🔨

一個有趣的互動式打地鼠遊戲，採用可愛的設計風格和流暢的動畫效果。

## 🎮 遊戲特色

### 三種難度級別
- **簡單**：30秒時間，8個洞位
- **中等**：25秒時間，9個洞位  
- **困難**：20秒時間，16個洞位

### 遊戲玩法
1. 選擇難度級別
2. 點擊「開始遊戲」按鈕
3. 快速敲打出現的地鼠 🐭
4. 每敲打一隻地鼠得 1 分
5. 時間結束時遊戲結束，展示最終分數

### 視覺效果
✨ 彩虹漸層背景  
🎨 流暢的跳躍和搖擺動畫  
💥 敲打地鼠時的擊中效果  
📱 完全響應式設計（支援手機、平板、桌面）

## 🚀 快速開始

### 方法 1：使用 Python 內置伺服器
```bash
cd whack-a-mole
python3 -m http.server 8000
```
然後在瀏覽器中打開：`http://localhost:8000`

### 方法 2：直接打開
在瀏覽器中打開 `index.html` 文件

## 🎯 遊戲技巧

- 🔥 難度越高，地鼠出現速度越快
- 👀 要小心！錯過的地鼠會很快縮回去
- 🏆 努力達到高分吧！

## 🎨 技術細節

- **框架**：純 JavaScript（無依賴）
- **動畫**：CSS3 動畫和過渡效果
- **瀏覽器兼容**：所有現代瀏覽器

## 💡 代碼高亮

遊戲使用 OOP 設計模式，包含以下主要特性：

- `WhackAMoleGame` 類：管理遊戲狀態和邏輯
- 事件驅動的敲打檢測
- 動態的洞位生成
- 計時器和難度管理
